# Blanketter

Lägg tomma blanketter och mallar i den här mappen. De visas automatiskt på sidan **Blanketter** efter publicering.

- Word: `.docx`, `.doc`
- PDF: `.pdf`
- Excel: `.xlsx`, `.xls`
- PowerPoint: `.pptx`, `.ppt`

Undermappar blir kategorier, till exempel `blanketter/Ledighet/Ansökan.docx`. Filer direkt i den här mappen får kategorin **Blanketter**.

DOCX och PPTX får en sökbar textvy. För övriga format söker appen på namn och kategori. Originalfilerna kan laddas ner; ingen ifylld blankett skickas in genom appen.

Mappen är för tomma blanketter. Ladda inte upp ifyllda personuppgifter till det offentliga repot.
