# Lägg dokument här

Ladda upp Word- och PowerPointfiler med GitHub → Add file → Upload files och spara till main.

Undermappens namn blir kategori, exempelvis `dokument/Arbetsmiljö/Min rutin.docx`.

- `.docx` och `.pptx`: fulltextsökning och textvy i appen.
- `.doc`, `.ppt` och `.pdf`: nedladdning och sökning på filnamn/kategori. Konvertera äldre Office-format till docx/pptx för textsökning.
- Bilder, diagram och fullständig layout finns i originalfilen. Text i inbäddade bilder OCR-tolkas inte.

Efter varje ändring bygger GitHub Actions om handboken automatiskt. Se status under Actions.
Inga riktiga rutiner är inkluderade från början.
